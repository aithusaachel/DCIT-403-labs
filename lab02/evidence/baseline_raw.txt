[04_no_tool] Q: What does PEAS stand for in AI agent design?
A: **PEAS** is a mnemonic used in AI to describe the four key components that define an agent’s task environment. It stands for:

| **P** | **E** | **A** | **S** |
|-------|-------|-------|-------|
| **Performance measure** | **Environment** | **Actuators** | **Sensors** |

### What each component means

| Component | What it represents | Typical examples |
|-----------|--------------------|------------------|
| **Performance measure** | The criteria used to judge how well the agent is doing. It defines the goal or objective the agent is trying to achieve. | Score in a game, profit in a trading system, accuracy of a classification task. |
| **Environment** | The external world in which the agent operates. It includes everything the agent can perceive and act upon. | A physical robot’s surroundings, a virtual game world, a financial market. |
| **Actuators** | The means by which the agent can affect the environment. These are the “output” mechanisms. | Robot motors, a software agent’s API calls, a trading system’s order‑placement interface. |
| **Sensors** | The means by which the agent perceives the environment. These are the “input” mechanisms. | Cameras, microphones, market data feeds, user input. |

### Why PEAS matters

- **Specification**: PEAS helps designers clearly articulate the problem the agent must solve.
- **Design guidance**: By breaking down the task into these four parts, you can systematically choose appropriate algorithms, architectures, and hardware.
- **Evaluation**: The performance measure gives a concrete way to assess and compare different agent designs.

### Quick example

| Component | Example for a self‑driving car |
|-----------|------------------------------|
| Performance measure | Minimize travel time while staying safe and obeying traffic laws. |
| Environment | Road network, traffic, pedestrians, weather. |
| Actuators | Steering wheel, throttle, brakes, turn signals. |
| Sensors | Cameras, lidar, radar, GPS, speedometer. |

So, **PEAS** is a handy shorthand for the four pillars that shape any AI agent’s design.
